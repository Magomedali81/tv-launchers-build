# tv-launchers-build

Сборка APK лаунчеров для **TV Doctor** из открытого исходного кода сообщества cleanyourtv.

* Каждый лаунчер собирается из **закреплённого коммита** (`lock.json`), исходники которого проверены вручную.
* Используется только официальный Gradle (не `gradle-wrapper.jar` из чужих репозиториев).
* После сборки `scripts/scan_apk.py` проверяет готовый APK: разрешения и сетевые адреса должны совпасть с проверенными, нет нативного кода, динамической загрузки кода, майнинга, доступа к SMS/контактам/камере/микрофону. Если что-то не так — APK не публикуется.
* Все APK подписаны одним ключом владельца (секреты `KEYSTORE_B64`, `KEYSTORE_PASS`).
* Готовые файлы и отчёты — в релизе `latest`.

## TV Clock

Собственное приложение часов поверх экрана (папка `tvclock/`): дата и/или время в выбранном углу. Без интернета, без сторонних библиотек. Настраивается из TV Doctor.
